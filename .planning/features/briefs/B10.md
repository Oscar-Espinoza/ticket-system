## Build
- **Drafts**: the new-issue dialog autosaves (debounced ~800 ms) to `issue_draft` once it has content (title or description), updates the same draft, deletes it on successful create; closing keeps it ("Draft saved" hint). `/dashboard/drafts` lists drafts across projects (title, project, updated) — open resumes it in that project's issues page (e.g. `?draft=<id>` which the dialog picks up; since IssuesView is B5's, open the dialog from your `IssueShortcuts` slot component when `?draft=` is present), delete, "Discard all".
- **Create more**: toggle in the dialog footer; after a successful create, keep the dialog open, clear title/description, keep chosen properties, refocus title. ⌘Enter submits.
- **Templates**: settings page CRUD (name, title, description, default state/priority/assignee/labels/estimate) using the pickers; in the new-issue dialog a "Template" menu applies one (fills empty fields + properties); palette commands "New issue from template: …" when inside a project.
- **Undo**: every issue mutation through `useIssueMutations` pushes an inverse operation (patch inverse, archive↔unarchive, delete↔restore); success toasts get an "Undo" action; ⌘Z (not in text fields) undoes the last one within the session; keep a small stack (20).
- **Copy**: on the focused or open issue — ⌘. copies the ID (`APP-12`), ⌘⇧, copies the permalink URL (`/dashboard/projects/<id>/issues/<KEY>` absolute), with toasts; also as `…` menu items (`menu-extra-items.tsx`: Copy ID, Copy link, Copy as markdown link, Duplicate issue (creates a copy with the same properties), Save as template).
- **Per-issue shortcuts** (registered in `IssueShortcuts`, scope "Issue", acting on the focused row/card (`[data-issue-row]`/`[data-board-card]` → id) or else the open issue `selectedIssue`): `s` status, `p` priority, `a` assignee, `i` assign to me, `l` labels, `e` estimate, `shift+d` due date, `⌘⌫` move to trash (with confirm), `shift+a`? archive — open the matching `…Options` picker from `src/components/issue-pickers` inside a small command Dialog anchored centre-top (Linear style).
