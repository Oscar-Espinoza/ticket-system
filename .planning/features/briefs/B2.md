## Build
- **Dispatch** (`dispatchNotifications(events)`, called by the event bus after the response): recipients = issue subscribers (`getSubscriberIds` from `src/lib/subscriptions.ts`) plus: new assignee on assignment (`issue.updated` change field `assigneeId`), mentioned users on `comment.created` / `description.mentioned`. Never notify the actor. Auto-subscribe the creator on `issue.created` and the new assignee on assignment (`ensureSubscribed`). Notification types: `assigned`, `mentioned`, `commented`, `status_changed` (state change on a subscribed issue), `completed`, `reminder`, plus `github` for PR merged. Respect `user_profile.notificationPrefs[type]` (default on) and `emailNotifications`. Email via `sendEmail` from `src/lib/email.ts` with a concise text + simple HTML template linking to the issue permalink (`${NEXT_PUBLIC_APP_URL}/dashboard/projects/<id>/issues/<KEY>`); set `emailedAt`. Batch DB inserts; never throw.
- **Inbox page** `/dashboard/inbox`: two-pane Linear inbox — left list grouped per issue (latest notification, actor avatar, issue key+title, type sentence, relative time, unread dot), filters All / Unread, right pane with the notification details and the issue summary (title, state, priority, assignee, description rendered with `Markdown` from `src/components/editor` if present at the end — else plain text) and an "Open issue" link to the permalink page. Actions: mark read (on open) / unread, archive (single + "archive all read"), snooze (1 hour, tomorrow 9:00, next week, pick date) — sets `snoozedUntil`; snoozed items reappear when due. Keyboard: j/k move, Enter open, u toggle read, e archive (register via the hotkey registry so `?` lists them). Hidden: `archivedAt` set, or `snoozedUntil > now`. Server-rendered + actions + `router.refresh()`.
- **Badge**: unread count next to Inbox in the sidebar (cheap count query; poll every 60s while visible, or refresh on navigation), and "(N)" prefix is NOT needed.
- **Preferences** `/dashboard/settings/notifications`: email on/off, per-type toggles, and a "Send test email" button. Server actions upsert `user_profile`.
- **Reminders**: `header-remind.tsx` — "Remind me" popover (in 3 hours, tomorrow, next week, custom date/time) creating a `reminder` notification for the current user with `snoozedUntil` = the time (it surfaces in the inbox then); show the pending reminder with a cancel option.
