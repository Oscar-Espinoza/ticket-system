- **Settings → GitHub** (admin): connect GitHub account (link with elevated scopes; show granted scopes), pick a repository from the user's repos (search), save `project.githubRepo`, register the webhook (`pull_request`, `push`; random secret in `project.githubWebhookSecret`, id in `githubWebhookId`, URL `${NEXT_PUBLIC_APP_URL}/api/webhooks/github`; warn clearly when the URL is localhost — GitHub can't reach it), automation state selects (PR opened → `githubPrOpenStateId`, default first started state named "In Review" else last started; PR merged → `githubPrMergeStateId`, default first completed), disconnect (delete webhook, clear fields).
- **Branch**: `header-github.tsx` — "Copy git branch name" (Linear format `<github-login-or-username>/<key-lowercase>-<slugified-title>` capped ~60 chars; store it on `ticket.githubBranch` via an action when first used), ⌘⇧. hotkey on the open issue, and "Create branch on GitHub" (from the repo's default branch head via `git.createRef`; handles "already exists"; records `githubBranch`, emits `github.branch_created` with `data.summary`). Disabled with a tooltip when no repo is connected / user lacks a token.
- **Webhook route**: verify `X-Hub-Signature-256` (timing-safe) against each project whose `githubRepo` matches `repository.full_name`; `ping` → 200. `pull_request` opened/reopened/ready_for_review/edited/closed/synchronize: find referenced issues by branch name (contains `key-number`), title, or body (`KEY-123`), upsert `github_pull_request`, emit `github.pr_linked`/`github.pr_merged`/`github.pr_closed` (actor null, `data.summary`), move state: opened & not draft → PR-open state (only if the issue isn't already started later/closed); merged → merge state (magic words: only issues referenced with closing words `close[sd]? | fix(e[sd])? | resolve[sd]?` + key, plus the branch's issue, get closed; non-closing references like `ref`, `part of`, `related to` just link). `push` to the default branch: commit messages with closing words close the referenced issues. Use the issue service layer with `actor { userId: null }`. Return 2xx fast; errors logged.
